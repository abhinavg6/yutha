# Reference

The canonical source of truth for the protocol, the wire formats, and the project's evolution. Most readers won't need these pages directly — the [concepts](../concepts/index.md), [operator guide](../operator/index.md), and [developer guide](../developer/index.md) cover almost everything. The reference is here when you need to settle a question definitively or when you're implementing against the spec.

- **[Specs](specs.md)** — the wire and artifact specifications. Versioned, RFC-governed.
- **[RFCs](rfcs.md)** — the change archive. Every spec change is preceded by an RFC.
- **[Canonical actions](canonical-actions.md)** — the registry of action kinds that may appear in receipts.
