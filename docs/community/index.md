# Community

Yutha is open-source, Apache 2.0, stewarded by a single maintainer right now. These pages cover how to contribute, the project's code of conduct, how security issues are handled, and the RFC process for spec changes.

- [Contributing](CONTRIBUTING.md) — how to file an issue, open a PR, or propose a feature.
- [Code of conduct](CODE_OF_CONDUCT.md) — the Contributor Covenant applies in every project space.
- [Security policy](SECURITY.md) — how to report vulnerabilities and what you can expect.
- [RFC process](RFC_PROCESS.md) — how spec changes are proposed, discussed, and merged.
