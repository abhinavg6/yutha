# yutha (Python SDK)

Async Python client for the [Yutha](https://yutha.dev) agent-coordination
control plane.

> **Status: 0.1.0a1, work in progress.** Stage 3 of Workstream D. The
> 3a slice (this revision) ships the package skeleton, protobuf codegen,
> and a clean `import yutha`. Ergonomic models (Passport, Envelope,
> Capability) and the high-level `YuthaClient` land in 3b and 3c. The
> LangGraph adapter is a separate stage (Stage 4).

> 👉 **New here?** Start with the
> [LangChain & LangGraph guide](../../docs/developer/langgraph.md) —
> a 15-minute hands-on that takes you from "fresh agent" to "five-agent
> LangGraph workflow with capability gating and a full audit trail." It
> uses everything below, so you don't need to read this README first.

## What's here

- `src/yutha/_proto/` — protoc-generated message + service stubs for
  every `.proto` under [`/spec/`](../../spec). Generated by
  `scripts/codegen.py`, committed so end-users never need
  `grpcio-tools`.
- `scripts/codegen.py` — regenerate `_proto/` from `/spec/`. Rewrites
  the generated imports to be absolute (`from yutha._proto import …`)
  so the package is importable without `sys.path` games.
- `pyproject.toml` — hatch build backend, runtime deps (`grpcio`,
  `protobuf`, `cryptography`, `pydantic`), dev deps
  (`grpcio-tools`, `pytest`, `ruff`, `mypy`).

## Install for development

```bash
cd sdks/python
pip install -e '.[dev]'
```

## Regenerate the wire stubs after editing `/spec/`

```bash
python scripts/codegen.py
```

The script wipes `src/yutha/_proto/` (except the hand-written
`__init__.py`), re-runs `protoc`, rewrites imports, and smoke-imports
every generated module. CI verifies that `_proto/` is in sync with
`/spec/` by running this script and diffing the working tree.

## Running the test suite

Unit tests (no network, no live server needed):

```bash
pytest -q
```

The integration test (`tests/test_integration.py`) exercises the full
Python → Rust lifecycle: register-already-done-by-server, mint a
bearer token, issue a capability, send an envelope to self, receive
it on the streaming subscribe, query the receipts. It's skipped by
default because it needs a running Rust control plane that the
Python side can authenticate against.

To run it, pick a 32-byte seed and start both sides with it. The
seed deterministically derives the bootstrap agent's signing key,
agent id, and the swarm id — both sides arrive at the same triple
without any out-of-band coordination.

```bash
# 1. Pick any 32-byte hex seed.
SEED=$(python -c "import secrets; print(secrets.token_hex(32))")

# 2. In one terminal: start the Rust control plane with that seed.
YUTHA_BOOTSTRAP_SEED=$SEED cargo run -p yutha-control-plane

# 3. In another terminal: run the Python integration test with the
#    same seed.
cd sdks/python
YUTHA_BOOTSTRAP_SEED=$SEED pytest -m integration -v
```

Override the gRPC address with `YUTHA_GRPC_ADDR`
(default `127.0.0.1:50051`).

**Note on the bootstrap seed.** Anyone holding the seed can act as
the bootstrap agent on that server. It travels through the same
trust boundary as any production secret — env var or file. Prefer
env vars over `--bootstrap-seed` on the CLI so it doesn't appear in
`ps aux`. Do not reuse a development seed in production; production
bootstrap keys should come from a KMS-backed source.

## Architecture (preview, lands in later stages)

```
                ┌──────────────────────────────────────────┐
                │  yutha.YuthaClient                       │
                │  ─────────────────                       │
                │   .admission  →  AdmissionService stub   │
                │   .capability →  CapabilityService stub  │
                │   .envelope   →  EnvelopeService stub    │
                │   .receipt    →  ReceiptService stub     │
                └─────────────────┬────────────────────────┘
                                  │
                ┌─────────────────▼───────────────┐
                │  yutha.auth.BearerSession       │  ← mints + refreshes
                │  (Ed25519 over canonical bytes) │     AgentBearerToken
                └─────────────────┬───────────────┘
                                  │
                ┌─────────────────▼───────────────┐
                │  yutha._proto.*  (grpcio stubs) │
                └─────────────────────────────────┘
```
