# yutha-sim

Simulation harness + canonical personas for Yutha constitutions.

Phase 3e / Pillar 1 (simulation + observability) of the Yutha workstream. Drive a candidate constitution against synthetic agent traffic — generated by a small set of well-defined personas — in a fully in-memory stack. No control plane needed; no network calls; deterministic by construction.

Three workflows make `yutha-sim` load-bearing:

- **Pre-promote dry-run.** Before activating a tightened constitution, operators want to know "what will my refund-attacker persona do under this new forbid rule?" Run a 30-step simulation, count the resulting denies + enforcement.detect emissions.
- **Constitution regression test.** Wrap a simulation in a `#[test]` and assert the receipt-count delta. A PR that loosens a forbid rule fails the test if the canonical refund-attacker persona stops getting denied.
- **Operator-doc walkthrough.** Embed the simulation output in operator-facing documentation to demonstrate what an enforcement rule actually fires on.

## Three canonical personas

Per the locked Phase 3 plan: infrastructure + opinionated examples, not a sprawling persona library.

- **`support_agent`** — well-formed support-queue envelopes; respects capability scope; never trips enforcement. Baseline traffic.
- **`refund_attacker`** — escalating refund probes; on Cedar deny, retries with larger amounts to probe the forbid threshold; on quarantine, recognises the state and gives up. Adaptive.
- **`broken_tool`** — out-of-scope cap-checks + missing capability_id sends. Triggers `capability.check.deny` + downstream enforcement chain firing.

## Three operator surfaces

- **Rust library** — `cargo run -p yutha-sim --example refund_attacker_meets_tightened`.
- **YAML scenario format** — declare the scenario in `scenario.yaml`, execute with `yutha-ops sim --scenario scenario.yaml`.
- **Python SDK** — `from yutha import run_scenario` then `run_scenario("scenario.yaml")` returns a typed `SimulationOutcome` dataclass.

## Phase status

Pre-1.0 alpha. The `Persona` trait, `SimContext` API, and `ScenarioConfig` YAML shape are subject to change before first public release.
